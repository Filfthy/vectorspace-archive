About AGENT X

Vector cabinet space combat / contract game

Fonts

Agent X Facet — original angular vector alphabet developed from the hand-drawn Agent X lettering.

Used for the Vector Space opening screen and the persistent Agent X terminal chrome: identity, operator statistics and primary navigation tabs.

Agent X Vector Sans — original single-line vector face used for the rest of the interface and in-flight lettering for clearer reading.

Uses straight segments, true elliptical arcs and Bezier curves. Both faces are built into the game; no third-party font file is required.

Agent X Line Text — compact straight-segment companion face retained in the source font set.
